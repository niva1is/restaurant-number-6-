# Restaurant-number-6 – система заказа еды по QR-коду

[![Frontend: React](https://img.shields.io/badge/Frontend-React_+_Vite-61DAFB)](https://reactjs.org/)
[![Backend: Node.js](https://img.shields.io/badge/Backend-Node.js_+_Express-339933)](https://nodejs.org/)
[![Database: PostgreSQL](https://img.shields.io/badge/DB-PostgreSQL-4169E1)](https://www.postgresql.org/)

**Restaurant-number-6** — это современное веб-приложение для ресторанов и кафе, которое заменяет физические меню и бумажные чеки, автоматизирует процесс приема заказа. Гость сканирует QR стола, оформляет заказ без регистрации; кухня ведет приготовление, официант получает готовые заказы и мгновенные вызовы от столов.

## Возможности

### Для гостя (Клиентская часть)
- **Сканирование QR:** Автоматическое определение номера стола.
- **Интерактивное меню:** Фильтры по категориям, поиск, детальные карточки блюд с фото и КБЖУ.
- **Умная корзина:** Изменение количества, добавление модификаторов (без лука, добавить сыр).
- **Real-time статусы:** Отслеживание статуса заказа в реальном времени.
- **Без регистрации** Для заказа не требуется регистрация

### Для персонала (Админ-панель)
- **Дашборд кухни:** Мгновенное получение новых заказов.
- **Управление статусами:** Возможность менять статус блюд/заказа в один клик.
- **Генератор QR:** Создание уникальных QR-кодов для новых столов.

## Как это работает

1. На каждом столе наклеен уникальный QR-код, содержащий зашифрованный `table_id`.
2. Гость сканирует код камерой смартфона. Открывается PWA-версия сайта.
3. Клиент выбирает блюда и нажимает "Заказать".
4. Backend сохраняет заказ в БД и отправляет событие через **WebSocket**.
5. На планшете на кухне или у waiter'а мгновенно появляется уведомление о новом заказе.
