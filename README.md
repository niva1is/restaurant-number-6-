
Фронтенд-часть веб-приложения для ресторана, разработанная с использованием современных технологий: React, Vite и TypeScript.

## Технологии

- **React** — библиотека для построения пользовательского интерфейса.
- **Vite** — быстрый инструмент сборки и сервер разработки с поддержкой горячей перезагрузки модулей (HMR).
- **TypeScript** — типизированный JavaScript для надежности и масштабируемости кода.
- **Oxlint** — быстрый линтер для поддержания качества кода и соблюдения стандартов.
