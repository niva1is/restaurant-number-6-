 Restaurant App (Фронтенд)
Фронтенд-часть веб-приложения для ресторана, разработанная с использованием современных технологий: React, Vite и TypeScript.
Технологии
React - библиотека для построения пользовательского интерфейса
Vite - быстрый инструмент сборки и сервер разработки
TypeScript - типизированный JavaScript для надежности кода
Oxlint - быстрый линтер для поддержания качества кода
Установка и запуск
1. Убедитесь, что у вас установлен Node.js
